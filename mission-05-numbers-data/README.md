## 4. My understanding
Computers process all data fundamentally as binary bits (0s and 1s). Hexadecimal provides a compact shorthand for reading binary byte patterns. Furthermore, character encoding standards like ASCII and UTF-8 are essential to map numeric binary values reliably to human-readable letters, symbols, and multilingual text.
